# Node.js API Service

This directory is reserved for the Node.js/Express API service.

The API service will act as the communication layer between client interfaces
and backend components. It will receive requests, validate incoming data, and
coordinate access to routing, ETA prediction, and persistence services.

## Planned Responsibilities

- Receive REST API requests
- Validate request data
- Access delivery and route information
- Communicate with backend processing services
- Return route and ETA information to client applications
